# 오리 인형 회상

현재 거실 인형 클릭 → 과거 거실 추격 → 인형 뺏기 → 플레이어가 직접 화장실 문을 열고 세탁기로 이동 → 세탁기 시작 버튼 클릭 → 자동 회상 연출.

- 세탁기 버튼은 렌더러 없는 콜라이더와 기존 PlayerInteractor로 처리합니다.
- 버튼을 누르기 전까지 플레이어 이동과 시점 조작이 유지됩니다.
- 세탁 관람 중에만 전용 재질로 드럼 앞면을 열어 인형의 회전을 보여줍니다. 기존 검은 원형 덮개와 초록 버튼 표시는 제거했습니다.
- 건조 후 인형을 플레이어 손으로 가져오고, 겨울이를 바라보며 건네줍니다.
- 겨울이가 집으로 달릴 때 카메라가 겨울이를 따라보다 문 쪽으로 고개를 듭니다.
- 마당에서는 문 앞에 도착하면 장면을 전환합니다. 집 안에서는 실제 문의 Transform을 열고 겨울이가 들어옵니다.
- 마지막 방석 장면은 UI 없이 3초 유지하고 Room3FlowController.CompleteVisit로 현재 시점에 복귀합니다.

조정 지점은 과거 거실 DollMemory의 Washer View, House Entry Outside/Inside, House Entrance View, Rest View와 마당 DollMemoryYard의 Drying View, House Door/Inside입니다. 기존 Player/Camera/Interactor 및 겨울이 Animator를 재사용합니다.

새 FBX 출력이나 Blender 수정은 없습니다. 바닥 충돌 구성은 이 수정에서 변경하지 않았습니다.

세탁기 본체는 전용 불투명 재질을 사용하며, 세탁 장면에서만 드럼 앞면을 엽니다. 물 셰이더 연결을 해제하고 반사광을 낮췄습니다. 세탁 동안 겨울이의 앉기 상태와 위치를 유지합니다. 건조와 방석 카메라는 제공된 참고 구도를 기준으로 배치했습니다.

마당 복귀는 기존 현관 계단의 각 단을 연결한 Stair Return Route를 사용합니다. 겨울이는 기존 바닥/계단 콜라이더의 실제 윗면 높이에 맞춰 걷고, 현관 문 앞에서 장면이 전환됩니다. 바닥 지지가 없거나 한 번에 오를 수 없는 높이는 이동을 중단하므로 바닥 관통을 방지합니다. 새 콜라이더는 추가하지 않았습니다.
