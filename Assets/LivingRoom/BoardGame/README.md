# BoardGame

게시판 클릭으로 시작. 기존 WASD 이동 / 마우스 시점 회전을 유지하며 화면 중앙 조준점을 사용합니다.

- 좌클릭: 집기, 떼기, 붙이기, 버리기, 최근 버린 물건 꺼내기
- Q/E: 물건 회전, F: 가까운 바닥에 내려놓기
- G 2초: 완성 검사. 키를 떼거나 일시정지하면 진행 시간이 초기화됩니다.
- 안내가 표시된 후 다음 좌클릭은 안내를 닫는 데만 사용됩니다.
- 작은 겹침 허용. 작은 쪽 면적의 25%를 초과하면 두 물건에 빨간 테두리를 표시하고 완성을 막습니다. 위치나 내용에 정답은 없습니다.
- 완료 결과는 현재 씬에서만 유지하며 다시 수정할 수 없습니다. 씬을 다시 불러오거나 게임을 재실행하면 씬에 지정된 초기 배치로 시작합니다. 저장하거나 이전 저장 파일을 읽지 않습니다.

모든 관련 에셋은 Assets/LivingRoom/BoardGame, 씬 오브젝트는 BoardGame 아래에 있습니다. 기존 게시판/쓰레기통을 재사용합니다. photo1~21의 Visual을 나중에 실제 에셋으로 교체할 수 있습니다. 크기를 바꾸면 BoardItem.size, BoxCollider, 테두리도 함께 조정해야 합니다.

Tools > LivingRoom > BoardGame > Set up and verify: 신규 설치 및 플레이 모드 검증. 이미 설치된 씬은 다시 생성하지 않아 수동 편집을 보존합니다.
