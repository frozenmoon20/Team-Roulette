# 뼈다귀 캐치 미니게임

`Room3_LivingRoom`의 `Bone_1` 클릭 → 기존 Room3 방문 흐름으로 `Room3_Toy` 입장 → 5회 캐치 → 축하·바라보기 → 완료 이벤트 → 거실 복귀.

`Room3_Toy`만 직접 실행하면 뼈다귀 게임을 미리 볼 수 있습니다. 실제 방문에서는 방문한 장난감 ID에 맞춰 테니스공·로프·뼈다귀 게임을 구분합니다.

## 조작

- 화면 상단 안내를 따라 겨울이 주변의 초록색 3D 링을 마우스로 조준하고 왼쪽 버튼을 누릅니다.
- 힘 조절 없이 약 0.36초 동안 짧게 던집니다.
- 왼쪽·오른쪽·위·앞 중 한 곳이 표시됩니다.
- 빗나가면 점수는 오르지 않고 겨울이가 주워 가져온 다음 다시 시도합니다.
- 설정 화면을 열면 투척과 이동 연출도 일시정지합니다.

## Inspector

Hierarchy의 `BoneGame` → `Bone Catch Game` 컴포넌트에서 설정합니다.

| 항목 | 기본값 / 용도 |
| --- | --- |
| Required Successes | 5회 |
| Flight Seconds | 0.36초 |
| Target Radius | 0.25m |
| Dog Distance | 2.1m |
| Side Distance | 좌우 0.65m |
| Jump Height | 위 0.65m |
| Forward Distance | 앞 0.55m |
| Squeak Clip | 기본 합성 삑 소리. 원하는 AudioClip으로 교체 가능 |
| Squeak Volume | 0.7 |
| On Completed | 축하·바라보기 후 한 번 호출 |
| Return To Living Room | 실제 방문 시 완료 후 기존 매니저로 복귀 |

## 재사용 및 보존

기존 Player, Camera, PlayerInteractor, GameUI, SceneUIContent, Winter 리그, Spitz_AContr_Demo 컨트롤러, Bone_1 Prefab과 GameManager를 사용합니다. 투척 중 원본 장난감은 잠시 숨기고 별도 복제본만 이동합니다. 원본 에셋·리그·오브젝트의 저장된 위치는 바꾸지 않습니다.

확인 당시 마당에는 NavMeshAgent와 구워진 NavMesh가 없었습니다. 가까운 평평한 마당에서는 짧은 직접 이동을 사용하며, 사용 가능한 NavMesh가 있으면 실패 회수·반환 경로에 사용합니다.

안내는 상단, 진행 목표는 기존 목표 UI에 표시합니다. 캐치 목표 자체는 LineRenderer로 만든 월드 공간 링입니다.

## 검증

Unity 메뉴 `Tools > Room3 > BoneGame > Verify Catch And LivingRoom Return`에서 실제 거실 입장·마우스 입력·실패 회수·네 방향 캐치·일시정지·5회 성공·거실 복귀를 검증합니다. 플레이 세션 안에서만 진행 단계를 조정하며 저장된 진행 상태는 수정하지 않습니다.

검사 결과는 `Editor/VerificationReport.txt`, 연결 확인 결과는 `Editor/SetupReport.txt`에 남습니다.
